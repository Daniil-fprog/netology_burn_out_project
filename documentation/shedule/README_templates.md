# Шаблоны импорта и экспорта · Мониторинг нагрузки и выгорания учителей

Все Excel-документы независимые. Каждый файл имеет лист `README`, схему колонок и синтетические примеры; для пустого шаблона удалить строки начиная с 5-й на листах данных.

## Импорт

| Файл | Содержимое |
| --- | --- |
| `IMPORT_teacher_norms.xlsx` | Нормативы учебной нагрузки |
| `IMPORT_daily_workload_plans.xlsx` | Ежедневный план |
| `IMPORT_daily_workload_actuals.xlsx` | Ежедневный факт |

**Совместимость с ранее написанным ТЗ:** текущий контракт импорта предполагает один XLSX с тремя листами. Отдельные файлы потребуют поддержки `import_type=norms|planned|actual` или аналогичного маршрута, а также проверки обязательных листов по типу. При импорте нормативов `effective_from` передавать в API отдельно. При импорте планов/фактов не доверять формульным итогам и проверять права на школу/учителя.

Опросники из исходного ТЗ создаются из версионированного JSON, а ответы отправляются через REST API; **Excel-импорт опросов не предусмотрен текущим контрактом**, поэтому не добавлен как якобы готовый к применению файл.

### Важные ограничения

- Директору разрешён только экспорт плановых данных своей школы. Полный план/факт, опросы, комментарии и NLP запрещены.
- Глава видит доступные ему школы; глава группы — школы в назначенных группах.
- Экспорт подробных комментариев и индивидуальных психологических данных требует специального разрешения; для ML предпочтительны псевдонимизированные данные и агрегаты.
- Синтетические эмоциональные оценки не являются диагнозом. Целевые метки модели выгорания не заполняются из самооценок автоматически.
- Экспортные примеры иллюстрируют формат ответа API, а не являются фактическими данными организаций.
